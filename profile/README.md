# What is an IPTV Player?

An **IPTV player** is software that allows users to stream television channels using an IPTV subscription. The player itself **does not provide channels**. Instead, it plays IPTV content using **M3U Playlists**, **Xtream Codes API**, or **Stalker Portal**.
